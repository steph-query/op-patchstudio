# Phase 1: Device Browser Test Coverage

The Device Browser feature (12 new files) has 0% test coverage. This phase adds comprehensive tests for utilities, hooks, and components.

## Priority 1: Utility Tests (Pure Functions)

- [ ] **Write tests for `src/utils/deviceXyParser.ts`** — This is the highest-risk code (binary manipulation). Create `src/test/utils/deviceXyParser.test.ts`. Tests should cover: (1) `parseXyPaths()` with a mock binary buffer containing known `/fat32/` paths, `content/` paths, and `#drum/` short refs — verify all path types are detected with correct offsets and classifications, (2) `parseXyFile()` with valid magic bytes `0xDDCCBBAA` and invalid magic bytes (should return empty), (3) `previewXyRename()` — construct a buffer with 2 occurrences of a path, call preview with old→new path, verify occurrenceCount=2 and correct sizeDelta, (4) `applyXyRename()` — verify binary data is correctly modified (old path bytes replaced with new path bytes), test both shorter and longer replacement paths, (5) `backupXyFile()` — mock FileSystemDirectoryHandle, verify backup file is created with timestamped name. Use the real `cracked_clay.xy` file in the repo root as a reference for building realistic test fixtures. Use `vi test` conventions from the existing test suite.

- [ ] **Write tests for `src/utils/devicePatchJson.ts`** — Create `src/test/utils/devicePatchJson.test.ts`. Tests should cover: (1) `readPatchJsonFromHandle()` with a mock FileSystemFileHandle that returns valid JSON with `type` and `regions` fields — verify parsed result, (2) `readPatchJsonFromHandle()` with invalid JSON (missing required fields) — verify returns null, (3) `writePatchJsonToHandle()` — mock writable, verify JSON is written with 2-space indent, (4) `updateSampleReferences()` — given a patch with regions referencing "old-sample.wav", call with oldName→newName mapping, verify all matching region.sample fields are updated and non-matching ones are untouched. Mock the File System Access API handles using simple objects with jest-compatible function mocks.
